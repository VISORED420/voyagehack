                      1. PROJECT OVERVIEW
================================================================================

Project Name: TBO GroupBook
Tagline: AI-Powered Group Booking Centralization Platform

--------------------------------------------------------------------------------
PROBLEM STATEMENT
--------------------------------------------------------------------------------

Wedding planners, corporate event managers, and travel agents managing group
bookings across multiple hotels face:

- Fragmented booking data across spreadsheets
- No real-time inventory visibility
- Manual payment tracking prone to errors
- Zero audit trail for dispute resolution
- No centralized guest management
- Inefficient communication with guests

--------------------------------------------------------------------------------
SOLUTION
--------------------------------------------------------------------------------

TBO GroupBook provides:

1. Centralized Dashboard - Single view of all bookings, payments, and inventory
2. Live TBO Integration - Real-time hotel availability and pricing
3. Complete Audit Trail - Every change tracked with before/after states
4. Smart Alerts - Proactive notifications for payments, inventory, and RSVPs
5. Multi-source Booking - Track bookings from microsite, phone, email, agents
6. Public Microsite - Self-service booking portal for guests

--------------------------------------------------------------------------------
AUTHENTICATION
--------------------------------------------------------------------------------

TBO API uses session-based authentication:

1. Authenticate with username/password
2. Receive TokenId (valid for ~30 minutes)
3. Include TokenId in all subsequent requests
4. Auto-refresh on token expiry

Code Implementation:
```python
class TBOClient:
    def __init__(self):
        self.token_id = None
        self.token_expiry = None

    async def authenticate(self):
        response = await self.client.post(
            f"{TBO_API_BASE}/Authenticate",
            json={
                "ClientId": TBO_CLIENT_ID,
                "UserName": TBO_USERNAME,
                "Password": TBO_PASSWORD,
                "EndUserIp": "127.0.0.1"
            }
        )
        self.token_id = response["TokenId"]
        self.token_expiry = datetime.now() + timedelta(minutes=25)
```

--------------------------------------------------------------------------------
API ENDPOINTS USED
--------------------------------------------------------------------------------

1. /Authenticate - Get session token
2. /HotelSearch - Search hotels with availability
3. /AvailabilityAndPricing - Get real-time rates
4. /HotelDetails - Get hotel information
5. /HotelBook - Create booking
6. /GetBookingDetail - Get booking status
7. /CancelBooking - Cancel booking

--------------------------------------------------------------------------------
ERROR HANDLING
--------------------------------------------------------------------------------

TBO API errors are handled with:

1. Exponential Backoff Retry:
   ```python
   @retry(
       stop=stop_after_attempt(3),
       wait=wait_exponential(multiplier=2, min=2, max=8)
   )
   async def search_hotels(self, params):
       # API call with automatic retry
   ```

2. Graceful Degradation:
   - If TBO is unavailable, fallback to cached data
   - Allow manual rate entry when search fails
   - Show clear error messages to user

3. Session Management:
   - Auto-refresh token before expiry
   - Re-authenticate on 401 errors
   - Queue requests during token refresh

IMPLEMENTATION
--------------------------------------------------------------------------------

```python
def log_audit(
    entity_type: str,
    entity_id: str,
    action: str,
    previous_state: dict = None,
    new_state: dict = None,
    performed_by: str = "system",
    event_id: str = None,
    booking_id: str = None
):
    # Calculate changes
    changes = {}
    if previous_state and new_state:
        for key in set(list(previous_state.keys()) + list(new_state.keys())):
            old_val = previous_state.get(key)
            new_val = new_state.get(key)
            if old_val != new_val:
                changes[key] = [old_val, new_val]

    # Create immutable log entry
    audit_entry = {
        "id": str(uuid4()),
        "timestamp": datetime.utcnow(),
        "entity_type": entity_type,
        "entity_id": entity_id,
        "event_id": event_id,
        "booking_id": booking_id,
        "action": action,
        "performed_by": performed_by,
        "previous_state": previous_state,
        "new_state": new_state,
        "changes": changes
    }

    # Store in append-only log
    audit_logs.append(audit_entry)
    return audit_entry
```

class BookingCreate(BaseModel):
    event_id: UUID
    guest_name: str = Field(..., min_length=2, max_length=100)
    guest_email: EmailStr
    guest_phone: str = Field(..., pattern=r'^\+?[1-9]\d{1,14}$')
    check_in_date: date
    check_out_date: date
    num_rooms: int = Field(..., ge=1, le=50)

    @validator('check_out_date')
    def check_out_after_check_in(cls, v, values):
        if 'check_in_date' in values and v <= values['check_in_date']:
            raise ValueError('Check-out must be after check-in')
        return v
