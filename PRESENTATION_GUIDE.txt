================================================================================
                      TECHNICAL INNOVATION POINTS
================================================================================

--------------------------------------------------------------------------------
1. OPTIMISTIC UI WITH CACHE INVALIDATION
--------------------------------------------------------------------------------

Dashboard loads in <100ms with Redis caching
Auto-invalidates on any booking/payment change

Cache Strategy:
  |-- Dashboard: 5 min TTL
  |-- Stats: 2 min TTL
  |-- Alerts: 1 min TTL
  +-- Auto-invalidate on mutations

--------------------------------------------------------------------------------
2. RESILIENT TBO INTEGRATION
--------------------------------------------------------------------------------

Exponential backoff retry with tenacity library:
- Retries up to 3 times
- Wait time: 2s -> 4s -> 8s (exponential)
- Never fails silently - graceful degradation

--------------------------------------------------------------------------------
3. OPTIONAL DATE SEARCH (PROBLEM -> SOLUTION)
--------------------------------------------------------------------------------

PROBLEM: TBO staging API returns "no availability" because staging has no
         real inventory

SOLUTION: Made dates optional
  |-- With dates    -> Live pricing from TBO
  +-- Without dates -> Hotel info only, manual rate entry

This allows demos to work even with API limitations!
