================================================================================
                     SUMMARY: KEY SYSTEM FLOWS
================================================================================

1. EVENT CREATION:     Host -> Dashboard -> Create Event -> Set Details -> Done

2. ROOM BLOCK SETUP:   Host -> Inventory -> Add Block -> TBO Search -> Select
                       Hotel -> Set Rates -> Save

3. GUEST BOOKING:      Guest -> Microsite -> Select Room -> Enter Details ->
                       Validate -> Submit -> Confirmation

4. PAYMENT TRACKING:   Admin -> Select Booking -> Record Payment -> Auto-update
                       Status -> Trigger Notifications

5. DASHBOARD VIEW:     User -> Dashboard -> Cache Check -> Aggregate Data ->
                       Calculate Stats -> Display with Alerts

6. AUDIT TRAIL:        Any Operation -> Capture Before -> Execute -> Capture
                       After -> Log Entry -> Immutable Storage

7. TBO INTEGRATION:    Search -> Session Check -> API Call -> Parse Results ->
                       Display/Book -> Store Locally
